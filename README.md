# Barrett Olson's Personal Website

This site was made using [Jekyll](http://jekyllrb.com/) and the [Cayman Theme](https://github.com/pages-themes/cayman)

### Preview locally

With Ruby 3.3 and Bundler available, run these commands from the checkout:

```sh
bundle install
bundle exec jekyll serve
```

Open [localhost:4000](http://localhost:4000/). Jekyll rebuilds when you edit
pages. Restart the server after changing `_config.yml`.
